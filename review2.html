Quick Grammar Notes

စာမေးပွဲအတွက် မှတ်သားရန်

Gerund

Verb + ing ကို noun အဖြစ် သုံးခြင်း။ Subject complement, object of preposition, direct object စသည်ဖြင့် အသုံးပြုနိုင်သည်။

Conditionals

Second: If + past simple, would + V1. Third: If + had + V3, would have + V3.

Passive Voice

be + V3. Modal passive: can + be + V3. အကြောင်းအရာကို အလေးပေးလိုသည့်အခါ အသုံးဝင်သည်။
