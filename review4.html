Quick Revision Notes

Exam-focused grammar reminders

Negative Prefixes

ir- responsible → irresponsible; in- considerate → inconsiderate; un- aware → unaware.

Suffixes

-ful = တစ်စုံတစ်ရာပြည့်ဝသော (powerful, graceful)။ -less = ကင်းမဲ့သော (merciless)။

As if / Tenses

as if + clause; past perfect = had + V3; past continuous = was/were + V-ing။
