01
CORE LESSON

Used to — Past habits

ဘယ်အချိန်မှာ သုံးမလဲ?

“Used to + infinitive” ကို အတိတ်ကာလတွင် ဖြစ်လေ့ရှိခဲ့သော အခြေအနေ သို့မဟုတ် ထပ်ခါတလဲလဲ လုပ်လေ့ရှိခဲ့သော အလုပ်တစ်ခုသည် ယခုအခါ ပြောင်းလဲသွားပြီဖြစ်ကြောင်း ဖော်ပြရန် အသုံးပြုသည်။

She used to be a quiet person when she was younger.

သူမ ငယ်စဉ်က တိတ်ဆိတ်ငြိမ်သက်သောသူတစ်ယောက် ဖြစ်ခဲ့သည်။

I didn’t use to eat vegetables, but now I know the benefits of eating vegetables.

အရင်က ကျွန်ုပ်သည် ဟင်းသီးဟင်းရွက်များကို မစားလေ့ရှိခဲ့သော်လည်း ယခုအခါ စားသုံးခြင်း၏ အကျိုးကျေးဇူးများကို သိရှိလာပြီ။

Did you use to play here as a child?

သင်ကလေးဘဝတုန်းက ဒီမှာ ကစားလေ့ရှိပါသလား။

မှတ်ရန်

အငြင်းပယ်ဝါကျတွင် didn’t use to + infinitive၊ မေးခွန်းတွင် Did + subject + use to + infinitive? ဟု သုံးသည်။

02
CORE LESSON

Be used to — Familiarity

ဘယ်အချိန်မှာ သုံးမလဲ?

“Be used to” သည် တစ်စုံတစ်ရာနှင့် ရင်းနှီးကျွမ်းဝင်နေခြင်း သို့မဟုတ် အသားကျနေခြင်းကို ဖော်ပြသည်။ ၎င်းသည် အတိတ်၊ ပစ္စုပ္ပန် သို့မဟုတ် အနာဂတ်အကြောင်းကို အခြေအနေအလိုက် ဖော်ပြနိုင်သည်။

My younger sister is used to doing challenging tasks.

ကျွန်ုပ်၏ညီမငယ်သည် ခက်ခဲသောတာဝန်များကို လုပ်ဆောင်ရသည်မှာ အသားကျနေသည်။

He wasn’t used to walking so much and his legs hurt after the hike.

သူသည် ဤမျှလောက် လမ်းလျှောက်ရသည်မှာ အသားမကျသေးသောကြောင့် တောင်တက်ပြီးနောက် ခြေထောက်များ နာကျင်ခဲ့သည်။

I live with my grandparents so I’m used to caring for older people.

ကျွန်ုပ်သည် အဘိုးအဘွားများနှင့် အတူနေသောကြောင့် အသက်ကြီးသူများကို ပြုစုစောင့်ရှောက်ရသည်မှာ အသားကျနေသည်။

အရေးကြီးသော ပုံစံ

be used to + noun / pronoun / V-ing ဖြစ်သည်။ “to” သည် infinitive marker မဟုတ်ဘဲ preposition ဖြစ်သောကြောင့် verb လိုက်ပါက -ing form သုံးရသည်။

03
CORE LESSON

Get used to — Becoming familiar

ဘယ်အချိန်မှာ သုံးမလဲ?

“Get used to” ကို တစ်စုံတစ်ရာနှင့် မရင်းနှီးသေးရာမှ တဖြည်းဖြည်း ရင်းနှီးကျွမ်းဝင်လာခြင်း၊ အသားကျလာခြင်း၏ process ကို ဖော်ပြရန် အသုံးပြုသည်။

I found learning French hard at first but now I’m getting used to it.

အစပိုင်းတွင် ပြင်သစ်ဘာသာစကားကို လေ့လာရသည်မှာ ခက်ခဲသော်လည်း ယခုအခါ ၎င်းနှင့် တဖြည်းဖြည်း အသားကျလာပြီ။

It took my mother years to get used to living in this city.

ကျွန်ုပ်၏မိခင်သည် ဤမြို့တွင် နေထိုင်ရသည်နှင့် အသားကျရန် နှစ်များစွာ ကြာခဲ့သည်။

I’m getting used to the noise now.

ယခုအခါ ထိုဆူညံသံနှင့် တဖြည်းဖြည်း အသားကျလာနေပြီ။

အရေးကြီးသော ပုံစံ

get used to + noun / pronoun / V-ing ဖြစ်သည်။ အနာဂတ်တွင်လည်း will get used to ကဲ့သို့ အသုံးပြုနိုင်သည်။

04
COMPARISON GUIDE

Remember the Difference

GrammarMeaning (မြန်မာ)Structure
Used toအရင်က လုပ်လေ့ရှိခဲ့သည်used to + V1
Be used toအသားကျနေသည်am/is/are/was/were + used to + V-ing
Get used toအသားကျလာသည်get/got/getting used to + V-ing
💡 Grammar Secrets

“I used to wake up early.” = အရင်က စောစောထလေ့ရှိခဲ့တယ်။

“I am used to waking up early.” = စောစောထရတာ အသားကျနေပြီ။

“I am getting used to waking up early.” = စောစောထရတာ အသားကျလာနေပြီ။

Negative: didn’t use to + V1 · Question: Did + subject + use to + V1?

Important: “be/get used to” မှာ to သည် preposition ဖြစ်၍ နောက်တွင် noun သို့မဟုတ် V-ing လိုက်ရသည်။
